# tensorcore ICC audit — 2026-06-26

Snapshot of the tensorcore codebase + cross-repo dependency graph
after Phase 4 (metric / geodesic / holonomic / shard) and Phase 5
(NumPy wrappers, Rust crate, bench harness) landed. Every number
below is what ICC actually sees against the freshly-indexed HEAD
(`a6eba3f`).

## TL;DR

**tensorcore is shippable today, one hardware gate from full
production sign-off.** 91/92 oracle criteria PASS across 9
completion oracles; only `metal4_tensorops_runtime_covered` is
outstanding, and it requires Apple M5 silicon to exercise.

The next-action queue is no longer about substrate gaps: every
op-family the unified-substrate vision called for now lives in
tensorcore as C/Eshkol + Python + Rust. The work in front of us is
**documentation hygiene** (557 unsupported claims), **cross-repo
adoption** (qLLM / QGTL / moonlab still hold parallel implementations
ICC can't yet see as superseded), and **eval scenarios** for the
operational edge cases.

## 5. Dead-code & test-coverage findings

**Dead code: 84 candidates.** Spot-checked the top entries:
- `flash_attention_*_kernel` + 9 other CUDA training kernels in
  `lib/cuda/training.cu` are flagged `real_orphan` but are launched
  via `<<<...>>>` syntax that ICC's call graph doesn't track. False
  positives.
- `shard_get` in `python/tensorcore/__init__.py` is `test_only_orphan`
  — accurate: only the Python substrate smoke calls it directly (the
  C test calls the C `tc_remote_shard_get`). Mark as
  `intentional_python_export` once attestation supports per-symbol
  tags, or leave — this is library code, not orphan.

**Test coverage: 2 test files vs 135 source.** Misleading.
ICC's test-coverage-audit counts files matching `test_*.{c,cpp}`;
most tensorcore "tests" are self-test scripts (`*_selftest.py`) +
ICC smokes (`check_*_runtime.py`). The real coverage is:
- 9 full ICC oracles (91/92 PASS)
- Fork-based 2-peer mesh + shard C tests
- 12 Rust integration tests
- 10 NumPy wrapper probes
- Per-op selftests for every check_* smoke

The "133 untested" number reflects ICC's narrow definition, not
production reality.
