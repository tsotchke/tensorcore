boundary-proven gate.

## What "complete tensorcore" means now

ICC reports `production-audit verdict: fail` and `stack-comprehension:
BLOCKED`. Both have well-defined exit conditions:

- **production-audit → PASS**: Tier 0 hardware acquisition + Tier 1
  fixes (≈100 LOC + 1 Mac purchase). Once those land, ICC's 7 risks
  resolve and the verdict flips.
- **stack-comprehension → L4_ADAPTER_BOUNDARY_PROVEN**: Tier 3 +
  Tier 4 orchestration work. No tensorcore code change required.

tensorcore the **substrate** is feature-complete for every shipping
consumer (qLLM, Noesis, tsotchke-chan, QGTL, moonlab) at the gate
level ICC graded today — 47/48 PASS, single hardware-gated fail. The
remaining tier-2 ops (ring-AllReduce, multi-qubit Lindblad jumps,
DiLoCo wiring) are quality improvements, not blockers.

The honest one-line answer to "what's required to complete
tensorcore": **buy an M5 Mac, fix one NotImplementedError, commit the
user-side preexisting changes, and run the sibling-repo re-indexes**.
Everything else in the queue is incremental polish on already-shipping
infrastructure.
